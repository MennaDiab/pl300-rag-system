# PL-300 RAG Tutor

RAG pipeline that answers Microsoft PL-300 exam questions using retrieval over
Microsoft Learn docs + exam material, with a local Ollama LLM (`qwen3:8b`) and
a Streamlit chat UI.

## Project structure

```
pl300_rag/
├── data/
│   ├── microsoft_learn/       # source PDFs (Microsoft Learn docs)
│   └── dumps/                 # source PDFs (exam dumps)
├── processed_data/
│   └── chunks.csv             # generated by 03_chunking.py
├── vector_db/
│   ├── pl300.index            # generated by 05_create_index_store.py
│   └── metadata.pkl
├── evaluation/
│   └── retrieval_evaluation.csv
├── 01_documents.py            # load raw PDFs into a DataFrame
├── 02_preprocessing.py        # clean_text()
├── 03_chunking.py             # chunk + save processed_data/chunks.csv
├── 04_vector_representation.py# embedding model helpers
├── 05_create_index_store.py   # build + save the FAISS index
├── 06_retrieve_context.py     # load index, retrieve(query, k)
├── 07_prompting.py            # build_prompt(), ask_llm(), answer_question()
├── evaluation.py              # Precision@K / Recall@K / Hit Rate@K / MRR
├── streamlit_app.py           # chat UI
├── requirements.txt
├── .env.example
└── .gitignore
```

## Setup

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Install [Ollama](https://ollama.com) and pull the model:
   ```bash
   ollama pull qwen3:8b
   ```
3. Put your PDFs in `data/microsoft_learn/` and `data/dumps/`.

## Build the index (run once, or whenever your PDFs change)

```bash
python 03_chunking.py          # -> processed_data/chunks.csv
python 05_create_index_store.py # -> vector_db/pl300.index + metadata.pkl
```

(Optional) evaluate retrieval quality:
```bash
python evaluation.py
```

## Run the Streamlit app locally

```bash
streamlit run streamlit_app.py
```
This opens the app at `http://localhost:8501`. Make sure Ollama is running
in the background (`ollama serve`, or just open the Ollama app).

## Pushing to GitHub

```bash
git init
git add .
git commit -m "Initial commit: PL-300 RAG pipeline + Streamlit app"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Notes:
- `.gitignore` already excludes the PDFs, the built FAISS index, and
  `processed_data/chunks.csv` — these are regenerable and can be large, so
  they're kept out of git. If you want to publish a demo without asking
  users to rebuild the index, remove those lines from `.gitignore` and
  commit `vector_db/` and `processed_data/chunks.csv` directly (check the
  file sizes first — GitHub has a 100MB per-file limit).

## Deploying (optional)

Ollama needs a persistent local process, so **Streamlit Community Cloud
cannot run this as-is** (no way to run Ollama there). Options:
- Run it locally / on your own machine or a university lab machine.
- Swap `ollama.chat(...)` in `07_prompting.py` for a hosted API (e.g. an
  Anthropic or OpenAI call) if you need a public demo link.
- Deploy on a VM/server where you also install and run Ollama.
