# PL-300 RAG Tutor

RAG pipeline that answers Microsoft PL-300 exam questions using retrieval over
Microsoft Learn docs + exam material, with an LLM served through
[OpenRouter](https://openrouter.ai) and a Streamlit chat UI.

## Project structure

```
pl300_rag/
├── data/
│   ├── microsoft_learn/       # source PDFs (Microsoft Learn docs)
│   └── dumps/                 # source PDFs (exam dumps)
├── processed_data/
│   └── chunks.csv             # generated by 03_chunking.py
├── vector_db/
│   ├── pl300.index            # generated by 05_create_index_store.py
│   └── metadata.pkl
├── evaluation/
│   └── retrieval_evaluation.csv
├── 01_documents.py            # load raw PDFs into a DataFrame
├── 02_preprocessing.py        # clean_text()
├── 03_chunking.py             # chunk + save processed_data/chunks.csv
├── 04_vector_representation.py# embedding model helpers
├── 05_create_index_store.py   # build + save the FAISS index
├── 06_retrieve_context.py     # load index, retrieve(query, k)
├── 07_prompting.py            # build_prompt(), ask_llm(), answer_question()
├── evaluation.py              # Precision@K / Recall@K / Hit Rate@K / MRR
├── streamlit_app.py           # chat UI
├── requirements.txt
├── .env.example
└── .gitignore
```

## Setup

1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Get a free API key from [OpenRouter](https://openrouter.ai/keys), then
   copy `.env.example` to `.env` and fill it in:
   ```bash
   cp .env.example .env
   # then edit .env and paste your OPENROUTER_API_KEY
   ```
   Pick any model slug from [openrouter.ai/models](https://openrouter.ai/models)
   for `OPENROUTER_MODEL` (some are free, e.g. models tagged `:free`).
3. Put your PDFs in `data/microsoft_learn/` and `data/dumps/`.

## Build the index (run once, or whenever your PDFs change)

```bash
python 03_chunking.py          # -> processed_data/chunks.csv
python 05_create_index_store.py # -> vector_db/pl300.index + metadata.pkl
```

(Optional) evaluate retrieval quality:
```bash
python evaluation.py
```

## Run the Streamlit app locally

```bash
streamlit run streamlit_app.py
```
This opens the app at `http://localhost:8501`. Make sure your `.env` file
has a valid `OPENROUTER_API_KEY` — the app loads it automatically.

## Pushing to GitHub

```bash
git init
git add .
git commit -m "Initial commit: PL-300 RAG pipeline + Streamlit app"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Notes:
- `.gitignore` already excludes the PDFs, the built FAISS index, and
  `processed_data/chunks.csv` — these are regenerable and can be large, so
  they're kept out of git. If you want to publish a demo without asking
  users to rebuild the index, remove those lines from `.gitignore` and
  commit `vector_db/` and `processed_data/chunks.csv` directly (check the
  file sizes first — GitHub has a 100MB per-file limit).

## Deploying (optional)

Since the LLM now runs through OpenRouter's API (not a local process), this
**can** be deployed to Streamlit Community Cloud:
1. Push the repo to GitHub (make sure `vector_db/` and
   `processed_data/chunks.csv` are committed — Community Cloud can't run
   your PDF/build pipeline for you).
2. On [share.streamlit.io](https://share.streamlit.io), create a new app
   pointing at `streamlit_app.py`.
3. In the app's **Settings → Secrets**, add:
   ```
   OPENROUTER_API_KEY = "sk-or-v1-..."
   OPENROUTER_MODEL = "qwen/qwen-2.5-7b-instruct"
   ```
   (Streamlit Cloud injects secrets as environment variables, so
   `load_dotenv()` + `os.environ.get(...)` in `07_prompting.py` picks them
   up automatically — no code change needed.)
